# Prasanna T — Portfolio

## Run it in VSCode

1. `File → Open Folder…`
2. Install the **Live Server** extension (by Ritwick Dey) from the Extensions panel (`Ctrl+Shift+X`, search "Live Server") or Install the **Live preview** extension (by microsoft) from the Extensions panel
3. Right-click `index.html` in the file explorer → **Open with Live Server**. / **open with Live preview**
   - This opens the site at `http://127.0.0.1:5500/index.html` and auto-refreshes on save.

## Notes

- Keep `Prasanna_Data_Analyst.pdf` and `Prasanna_Developer.pdf` in the **same folder** as `index.html` — the Contact section links to them by relative path.\
fonts , icons , few images are taken from the online sources like **Google font** / **Simple logo**
- The site needs an internet connection to load Google Fonts and the tech-stack logo icons (both from public CDNs). Your photo is embedded directly in the HTML, so that part always works offline.
- All code is in the single `index.html` file (HTML/CSS/JS together) — easiest place to make edits is inside the `<style>` and `<script>` tags near the top and bottom of the file.
